# デプロイ手順

ミッションビンゴを Cloudflare（無料プラン）に公開する手順。初回だけ 1〜3 が必要で、2回目以降は 4 だけでよい。

## 1. R2 を有効にする（初回のみ・ダッシュボード）

1. Cloudflare ダッシュボードにログインする
2. 左メニューの「R2 オブジェクトストレージ」を開き、R2 を有効にする
   - 無料枠の範囲で使えるが、有効化のときに支払い方法の登録を求められることがある

## 2. wrangler にログインする（初回のみ）

```sh
npx wrangler login
```

ブラウザが開くので、Cloudflare アカウントで許可する。`npx wrangler whoami` でログインできたか確認できる。

## 3. 画像用のバケットを作る（初回のみ）

```sh
npm run r2:setup
```

次の2つをまとめて行う。

- R2 バケット `mission-bingo-images` を作る
- 保険のライフサイクルルール（アップロードから7日で削除）を付ける
  - 通常はゲーム終了から24時間後に RoomDO が画像を削除する。このルールは消し忘れの保険

## 4. 公開する

```sh
npm run deploy
```

ビルドしてから `wrangler deploy` を実行する。初回は workers.dev のサブドメイン登録を求められることがある。表示された URL（`https://mission-bingo.<サブドメイン>.workers.dev`）が本番 URL。

## 動作確認

- 別々の端末（PC とスマホなど）で同じルームに入り、1ゲーム通しで遊べること
  - ルーム作成 → ロビーで参加 → ゲーム開始 → 申請・承認（画像も） → 終了 → 結果画面・結果画像の出力

## 補足

- 開発用の `.dev.vars`（`IMAGE_RETENTION_MS` で画像の保存期間を短くするもの）は本番では使わない。本番の保存期間は24時間
- `wrangler.jsonc` を変えたら `npx wrangler types` で型を作り直す
